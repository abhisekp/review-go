# bfs

Breadth-first search utilities including a `ShortestPath` helper that demonstrates BFS level traversal and uses internal `queue`, `set`, and `stackFromQueue` packages.

Files

- `bfs.go` — `ShortestPath` generic function and a `Person` sample type.

Usage

- Import the package and call `bfs.ShortestPath` with a graph map and a predicate function.
# async-traverse

Binary tree utilities: serialize and deserialize a tree using level-order (BFS) traversal. Includes synchronous inorder traversal for verification and a `Run` example.

Files of interest

- `main.go` — Contains `Node` type, `SerializeTree`, `DeserializeTree`, `InorderTraversal`, and `Run` example.

Usage

- Run the example: `go run ./async-traverse` or call the package's functions from another program.
