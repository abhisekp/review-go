# pipeline

Composable channel-based pipeline examples (`PipeFn`) with map/filter/reduce-like stages, fan-out/fan-in, and examples for numeric operations.

Files

- `pipeline.go` — implementations of `Pipe` utilities and example `WithPipe`/`WithoutPipe` runs.

Usage

- Run example: `go run ./pipeline` or call `pipeline.WithPipe()` from your `main`.
